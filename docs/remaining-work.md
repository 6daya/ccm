## 下一轮选择规则

先完成公司 A/B 小样本和内部知识回执，再从实测最主要的遗漏/返工/耗时选择一项改动。保留 baseline 快照、同一自然语言目标和验收；报告请求数、token、时间、实际费用与质量的共同变化。没有真实数据时只保留候选，不承诺节省百分比或新能力已实现。

免费 verifier 的独立上下文与程序检查能降低风险，不能保证设计语义正确。语义关键遗漏若持续出现，再决定补领域不变量、换验证模型或增加限定专家审查，不让每项任务默认调用昂贵模型。

## 安全升级

0.1.0 工作台先在原位置完成/取消任务，核对未知付费并保留状态/回执；新目录取得 0.2.0，重新登记仓库、模型、保护与验收，再重启一次。不要覆盖旧 .team-harness 或移动带绝对根路径的活动任务。公司全账户约 $1000/月目标由网关统一配额管理，各工作台估算账本不能相加后假设自动硬封顶。
