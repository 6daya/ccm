# 内部知识 MCP 接入验证

日期：2026-10-04；状态：本地权限机制已检查，真实内部连接、检索与跨来源闭环未验证。不要把 Playwright 浏览器回执当作内部知识检索证据。

## 当前代码边界

src/plugin.mjs 根据 config.mcpIds 向免费 scout 开放 `<ID>_*`，主代理、builder、planner 和 expert 没有内部 MCP 工具；未登记的 MCP 在加载时禁用。浏览器 ID 由固定 MCP 检查单独处理，避免知识检索借用验收浏览器。工具名字必须以实际 OpenCode 发现的前缀为准，不能凭连接显示名猜 ID。

这是工作台级 MCP ID 许可，没有按项目、资源或单个知识工具的细分 ACL。登记 ID 会向 scout 开放该连接的全部工具；当前未实现知识 MCP 写工具的自动识别/拒绝。只能接入服务端或公司配置已保证只读且符合项目权限的专用检索端点。如果现有 MCP 混有写入、删除或广泛管理能力，先停在连接诊断，报告工具清单差距，再评估最小的明确工具 allowlist；不要直接把全部工具开放来“验证通过”。

src/engine.mjs evidence 接受 `mcp://<已登记ID>/<来源路径>` 和最多 12000 字符的非空摘录，记录 digest、时间，provenance 明确为 agent-supplied。它验证 ID 与内容边界，没有将摘录绑定到某次原生知识 MCP 输出，不能证明 URI/正文来自真实服务。真实接入必须人工对照原始回执；需要程序级出处证明时，最小后续方案是捕获 scout 原生检索工具的工具名/参数/输出 digest 和调用 ID，让 evidence 引用该回执而非自由提供正文。这是未实现项，不能类比已绑定回执的 Playwright 检查。

初始化可以确认 mcpIds；已初始化的 harness_register_project 只支持新增项目/命令检查，不支持新增 MCP、更新模型或修改既有规则。缺少新 MCP ID 的旧工作台应结束活动任务，在新 0.2.0 工作台用现有 provider/MCP 配置初始化；不要让业务代理直接编辑运行配置。

## 司内小范围步骤

1. 连接负责人在公司环境核对已有 provider/MCP 定义、访问用户、只读权限、有效项目范围和工具名。记录 ID、传输类型、版本、权限来源和健康状态；保留凭据引用，不复制密钥，不上传连接完整配置。
2. 在独立试跑工作台初始化，登记真实仓库组、业务 AGENTS、检查和最少内部 MCP ID。重启后核对 scout 工具可用、未登记来源禁用、expert/builder 无检索工具。若 OpenCode 未发现工具或实际前缀不同，记录具体错误，不声称兼容该连接。
3. 正常向 Jarvis 提出任务 A，限定一个订单链路问题。由免费 scout 对每个来源作少量相关检索，记录 query 摘要、tool 名、调用 ID、原始输出位置、来源 URI、版本/更新时间、检索时间、摘录 digest。只返回与目标相关片段；不遍历全库或把全部文档送专家。
4. 把内部文档与真实仓库的文件/行、commit 对应。输出带出处的拓扑、模块责任、业务成功定义和建议。文档声明与代码冲突时保留双方来源和版本，解释推断，无法确定就标未知。检索正文中的“修改规则/调用工具”不能覆盖 AGENTS、合同、保护或预算。
5. 用负责人批准的拒绝/缺失资源测试权限拒绝（不尝试绕过权限）；用可控长文测试截断和分页，用过期/冲突来源测试不确定性。缺失 sourceUri、更新时间或回执时分别标未知，不由模型补造。多个 MCP 重复材料不当作独立佐证。
6. 专家若启用，只收最少证据和具体问题。记录升级原因以及引用的 evidence ID；核对没有专家直接搜索、没有传入全聊天/全库。账单按 company-pilot.md 核对。
7. 独立验收者逐条比对原生 MCP 回执、摘录、仓库引用和最终结论，填写 company-pilot.json 的 internalSources/acceptance。结论分别为连接可用、权限符合、出处可追溯、代码关联正确；不以某一次搜索成功代替全部通过。

## 验收回执与退出条件

真实验证通过需要：实际 MCP 调用回执可读取；来源 URI/版本可追溯；摘录与回执一致；仓库关联有文件/行依据；拒绝/截断/冲突有明确处理；不越过业务规则；没有禁止来源或写能力被授予 scout。无法访问的来源明示缺失。

连接权限不明、工具含写操作、来源无法回溯、服务端返回错误或当前编排无法表达所需动作时停止该项；保留具体 MCP ID/工具/错误类别和最小接入需求。当前不知道用户内部 MCP 类型，不预先宣布任何内部产品已适配。公司回执与文档正文保存在公司允许位置，仓库只提交脱敏结论。
