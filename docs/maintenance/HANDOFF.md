## 当前接续时必须知道

- 已交付 0.3.0；当前交付分支是 `feat/harness-baseline`，main 仍不是该交付版本。新任务若改分支/创建 PR，应以最新用户目标为准，不自动合并 main。
- 已有 57 项回归与真实 V2/Playwright MCP 完整链路证据；输入是模拟模型。首次引导/原生表单有实机总结，系统维护只测了 node --version，没有实际安装。
- 本机 V2 新原生缓存可启动；整机/司内网络冷安装、真实 GLM/DeepSeek/Opus 质量与总费用、内部知识 MCP 和 Windows 仍待验证。
- 先看 TODO 的 P1 使用证据，再选择一个 P2 改进。受限付费编码、更细路由、知识晋升、worktree、通用配置迁移和其他宿主未实现。
- 历史 0.1/0.2.x 文档仍在 docs，含旧 `.team-harness/` / Slim / V1 数值；当前入口是 maintenance 与 architecture，不按历史文件恢复旧实现。
- runtime major-V2 检查与“集成验证仅 2.0.23”不同；升级其他 V2 版本仍须重新验证。修改 stock Jarvis 时同步 init 的 SHA256 白名单，保护自定义 agent 不被覆盖。
